## Decisions made and why

- **Mobile nav:** bottom bar is Overview, Spending, raised Add, Bills, More. Savings, Insights, Plan, Reports, Categories, Data and the theme toggle live in a "More" bottom sheet. The desktop nav is unchanged.
- **Cloud is protected first:** the app never uploads before a successful load (`cloudLoaded`), hosted mode shows a blocking load/failure gate, a tab you return to refreshes quietly, and a waiting save is flushed when the tab hides. Reason: a device with empty or stale local data must never overwrite the sheet.
- **Cached data is not shown when the cloud fails to load** (hosted mode). Chosen for safety over offline viewing.
- **The script's error replies count as failures.** It answers HTTP 200 with `{error}` for a wrong token, which used to look like success.
- **Database migration: not decided.** The user chose to keep Google Sheets for now. See `docs/database-migration.md`.
- **Apps Script scope:** only the Status column, automatic column growth and JSON errors were shipped. Savings plan, shared sub-categories and a save lock were deferred.

## Gotchas

- **No `npx` on this machine.** Use `export PATH="$HOME/.nvm/versions/node/v24.21.0/bin:$PATH"` then `node node_modules/.bin/ng build --output-path <somewhere outside the repo>` and `node node_modules/.bin/tsc --noEmit --noUnusedLocals -p tsconfig.app.json`.
- **Development build** needs the git-ignored `src/environments/environment.development.ts`. Copy `environment.development.example.ts` (see README). It may hold a personal sync URL: never commit it.
- **Apps Script:** after any change use Deploy, Manage deployments, pencil, **Version: New version**. The URL stays the same. Each `const` may be declared once in the whole project (a duplicate caused a `SyntaxError` this session). The URL must end `/exec?token=...`; the app appends `&cacheBust=...`.
- **What "no readable reply" means:** the script threw or access is not Anyone, so Google served an error page. A wrong token comes back as JSON and the app says so. See `docs/sync-issue-breakdown.txt` for the full diagnosis order.
- **Cloud copy wins on load**, so any field the script does not store is lost on refresh.
- **Commit style:** short lowercase prefix, for example `fix ui : ...`, `fix : ...`, `docs : ...`, `chore : ...`. **Do not commit unless the user asks**, and end every change with a ready-to-paste commit message.
- **Key code** (`src/app/app.ts`, about 2400 lines): `loadFromApi`, `executeSyncToApi`, `mergeLocalPendingFlags`, `refreshOnReturn`, `flushPendingSync`, `showCloudGate`, `describeCloudError`, `allPendingTransactions`. Sections are switched by the `activeSection` signal. Data flow: signals, then `persist()` to localStorage, then a 1-second debounced `syncToApi` to the script's `replace` action.
